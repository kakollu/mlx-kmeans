# mlx-kmeans — AI session guide

Last updated: 2026-09-25

The record of this project lives in the repo itself, not here:

- `README.md` — what the library is and is not, how to measure it, the API.
- `BENCHMARKS.md` — generated by `bench.py --report` from `benchmarks/results.jsonl`; per-config times, floors, ratios.
- `benchmarks/NOTES.md` — the full engineering record, dated sections, including everything that did not work.
- `benchmarks/MACHINE-PROFILE.md` — measured facts about this M5 Max (bandwidths, ceilings, occupancy, cache curve).
- `benchmarks/possible.py` — what the hardware allows per config under each assumption.
- `meta/ai/project-state.md` — where things stand and what is open (this folder).
- `meta/ai/CODEX.md` — a recommendation from another model and its outcome.

Rules that hold for this repo (Satya, September 2026):
- Compare against the standard libraries in the suite (scikit-learn, FAISS, fast-pytorch-kmeans). No claims
  about other repositories; measurements of other implementations stay outside the repo.
- State results; do not claim to be the fastest or the best.
- Commits stay local until told to push. Push only on an explicit word.
- `tests/accuracy.py` (22 cases) and `tests/reuse.py` must pass before any commit that touches `mlx_kmeans/`.
